# Проверка первой версии · 25.09.2026

- `npm run build`: TypeScript и production bundle успешно собраны.
- `npm test`: 48 тестов проходят, SQLite in-memory, внешние API подменены. Включены 10 тестов адаптера Tickets.rs: время/DST, сербские обозначения `12h`/`20.00`, отдельные сеансы, цены, ваучеры, пагинация, повторы, география, изменившийся формат и ошибки.
- `npm run test:http`: временная SQLite; preview, import, повторный import, provenance, edit, каталог, schema, export, validation, Host/Origin checks проходят.
- `PRAGMA integrity_check`: `ok`, применены три SQL-миграции.
- Браузер: проверены Activities, Sources, JSON preview, карточка, редактирование/сохранение демо-события, обновление статусов; desktop и ширина 390 px. Дата/время вводятся текстом и валидируются, включая timezone и DST.

Реальный Overpass-запрос загрузил 341 raw-запись и создал 340 canonical-мест Белграда. Также извлечены 178 ссылок-кандидатов. Четыре demo-записи помечены отдельно. Повторные большие запросы к публичным серверам вернули HTTP 504/timeout: данные остались в БД, ошибки сохранены в истории. Это проверка обработки отказа внешнего сервиса, а не успешное повторное обновление.

Ticketmaster реализован, но live-вызов не выполнялся без пользовательского ключа. Остальные закрытые API не вызывались. На момент первой проверки местные афиши, кроме Tickets.rs, использовали экспериментальные JSON-LD adapters; результаты последующего аудита приведены ниже. Нет выдуманных успешных подключений или платных запросов.

## Исправление Tickets.rs · 25.09.2026

Общий JSON-LD reader заменён отдельным адаптером публичного JSON-интерфейса сайта. Проверены реальные ответы всех страниц Белграда и отдельно перечисленных районов. Пустые районы возвращают `CurrentPage=0` без выбранного фильтра города — это учтено в коде и тестах.

В работающем приложении через встроенный браузер выполнены «Проверить» и «Синхронизировать»: 566 входных записей, 0 ошибок. Пять записей без конкретной даты пропущены с явным предупреждением. При проверке первых результатов обнаружены восемь ошибочных объединений сеансов с сербским обозначением часа. Разбор времени исправлен; карточки разделены, все исходные версии сохранены. Перед исправлением создана резервная SQLite-копия в `data/`. Итог: 566 отдельных карточек; повторное применение того же пакета даёт 566 повторов, 0 новых/обновлённых.

Источник показывает «Подключён», `lastError=null`. Время есть у 391 записи, у 172 сохранена только дата. У трёх записей подпись не подтверждает конкретную дату (серия или продажа билетов): служебные даты сайта не используются, дата оставлена неизвестной. Отсутствующие время и цена не выдумываются. Пользовательские настройки источника сохранены. Поддерживается география Belgrade; импорт всей Сербии пока отключён явно.

Эти проверки не импортировали новые карточки и не включали выключенные источники. Исправлены города и площадки у 18 ранее загруженных записей Bilet.rs: 3 Belgrade, 3 Leskovac, 3 Niš, 2 Kruševac, 7 с неизвестным городом. Неизвестные города больше не считаются Белградом. Пользовательские изменения, заметки, избранное и исходные версии сохранены; перед исправлением сделана резервная SQLite-копия в `data/`.

`npm test`: 58 тестов проходят. Добавлены проверки географии, пагинации, изменившегося формата, пустых результатов, ошибок Overpass и признака регистрации. `npm run check` и production-сборка проходят.

В браузере проверены страница источников, компактные плашки «Регистрация» у 11 провайдеров и ссылка на нужный аккаунт в инструкции Ticketmaster. Публичные источники этой плашкой не отмечены. Существующая пользовательская вкладка и её несохранённое состояние не изменялись.
