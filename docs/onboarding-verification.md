# Проверка первого запуска — 19 октября 2026

Проверен сценарий двух соседних репозиториев на macOS Apple Silicon, Node 25.2.1
(минимум проекта — Node 24). Повтор: `node scripts/check-onboarding-clean.mjs`.

Helper копирует исходники текущих рабочих деревьев Activity Checker и Personal
Radar, включая ещё не опубликованные изменения. Не копирует `.env`, SQLite,
сессии, node_modules, dist, виртуальные окружения или глобальный MCP config.
Создаёт отдельные HOME, CODEX_HOME, Python и Chromium. Node/npm и uv берутся
из установленного toolchain; npm использует только кэш пакетов без пользовательского
npmrc. Это чистая установка приложения, не проверка на заново установленной ОС.

Успешно проверены:

- диагностика отсутствующих ключей, зависимостей, базы и Telegram-сессии;
- установка обоих npm-пакетов по lockfiles, нового Python 3.12 и Telethon;
- новая личная база без demo-карточек, повторная инициализация без потери данных;
- обнаруживаемые repo skills, схемы local research/Telegram tools, отдельный Chromium;
- production build, запуск HTTP-сервера, health, bootstrap и главная страница;
- профиль с молдавским/румынским и английским, отключённые условия образца,
  синхронизация промптов, реальных фильтров и исключений Telegram;
- Knowledge → local Community mapping → local CLI → Telegram review;
- JavaScript-страница → canonical import → фильтр кандидатов → публикация двух
  подходящих событий и одного отказа → рендер календаря и списка отказов;
- защита private network/POST/cookies, Caddy fallback и Node вне Finder PATH;
- реальный публичный HTTPS read через local CLI и Chromium без API-ключей.

Внешние данные сквозного теста синтетические: фактические Node/CLI/MCP/SQLite/HTTP
и Chromium работают, Telegram/HTTPS fixtures заменяют provider transport.
Реальные личные авторизация Telegram, FloodWait и доступность конкретных источников
проверяются после ввода собственных ключей пользователем. Платные провайдеры не запускались.
Не проверялись другие ОС и ответы модели на все возможные пользовательские формулировки.

Общие проверки: 397 тестов, `npm run check`, `npm run build`, `npm run test:http`.
Проверены формат repo skills, пути ссылок и блок «Дополнительно» в браузере.

До передачи коллеге нужно опубликовать согласованные актуальные версии **обоих**
репозиториев. Затем достаточно соседних клонов и вызова `$start` в локальном агенте;
установка предпосылок, личные ключи и подтверждение предпочтений остаются шагами диалога.
