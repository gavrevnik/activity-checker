# Источники активностей Кишинёва и Молдовы

Результат реализации и фактические ограничения подключённых источников:
[Молдова: коннекторы](../moldova-connectors.md). Ниже сохранено исходное исследование.


Проверено **16 октября 2026**. Цель — выбрать пул для будущего мониторинга,
а не подключить все источники или опубликовать подборку. Новые Community/sources,
подписки и записи Knowledge не создавались. Профиль, реакции и редактируемые
промпты не менялись. Проверка доступа — наблюдение на эту дату, не гарантия SLA.

## Что подключать первым

1. **Fest.md + iTicket.md**: основа автоматической афиши, пригодная для HTML/JSON-LD
   адаптеров. Fest шире билетной продажи; iTicket удобен для подтверждения времени,
   площадки и покупки. **Afisha.md** — третий крупный источник, но список динамический.
2. **Афиша Мира, Кишинёв**: найден и проверен JSON API **без ключа**, особенно полезен
   для русскоязычных гастролей. Дополнительно читать HTML карточки для даты события.
3. **Telegram @afficherchisinau**: лучший подтверждённый широкий RU-источник в недельной
   проверке; **@afisha_kishinev** — дополнительная афиша, **@guleaimd** — выборочно.
4. **Sporter + Moldova Travel + FRC Chisinau**: закрывают спорт, природу,
   гастрономические фестивали и регулярные совместные активности.
5. **Locals, Artcor, America House, Tekwill**: дополняющий веб-поиск по конкретным
   площадкам/организаторам; не выдавать их за полный машиночитаемый календарь.

Приоритеты — оценка полезности источника по этому ресерчу, **не aiScore мероприятий**.
Русскоязычные концертные/сценические события включать широко, но оценивать вкус честно.

## Предпочтения и география

Сохраняются четыре класса Белграда: спорт (особенно beginner padel/squash, бег,
велосипеды), прогулки/хайкинг, общение/разговорные клубы/караоке, концерты/стендап/
творческие встречи/фестивали еды и вина. RU предпочтителен, EN подходит.
Регулярное живое участие и возможность прийти одному важнее количества записей.
Квизы, настолки/D&D остаются 0–3/10; мода/текстиль и непрофильный бизнес-нетворкинг
понижаются по действующему `ai-events-review`. Румынский язык страницы не означает
язык программы. Для разговорных RO-only форматов нужен понятный язык/перевод;
еда, природа и визуальные выставки не штрафуются за местное происхождение.

Рабочая география: `scopeId=chisinau`, country `MD`, city `Chisinau`, timezone
`Europe/Chisinau`. Нормализовать Chișinău / Chişinău / Chisinau / Кишинёв / Кишинев.
Винодельни и походы за городом помечать фактической локацией и логистикой из
Кишинёва; событие в Сороках или Комрате не становится городским из-за источника.
Не копировать белградский каталог площадок и не менять общий профиль ради поездки.

### Бесплатный API без авторизации — подтверждён

У **Афиши Мира** выполнены анонимные GET, все HTTP 200:

- [География city/205](https://afishamira.com/wp-json/wp/v2/city/205): Кишинёв,
  slug `chisinau`, `count=80`; ответ сам ссылается на event endpoint.
- [Каталог событий](https://afishamira.com/wp-json/wp/v2/event?city=205&per_page=3):
  3 записи, `X-WP-Total: 80`, `X-WP-TotalPages: 27`. Страницы REST API поддерживаются
  WordPress; на реализации пройти реальную пагинацию, а не ограничиться тестовыми 3.
- [Метаданные типов](https://afishamira.com/wp-json/wp/v2/types): event REST type доступен.

Полезные поля: `id`, `modified`, `link`, `title.rendered`, `content.rendered`,
`city`, `artist`, `event_genre`. В тестовом ответе `acf=[]`: дата/время мероприятия
отдельными полями не получены. **`date`/`date_gmt` — публикация WordPress**, не начало.
Нужен гибрид REST catalogue + публичная карточка + проверка билетной страницы.
Бесплатность означает фактически доступное чтение без оплаты/ключа на дату проверки;
специального SLA, гарантированной квоты и лицензии на переиздание этим не установлено.

## Практическая очередь реализации

**Первый этап:** Fest HTML, iTicket HTML/JSON-LD, Афиша Мира REST + detail,
Telegram afficherchisinau и afisha_kishinev с country/city metadata и текущими
исключениями. Общая дедупликация по событию/дате/месту/билетной ссылке обязательна.

**Второй этап:** AllEvents Chisinau после проверки реальной пагинации, Afisha.md
через доступный анонимный renderer, Sporter/Moldova Travel, FRC и точечный web поиск.
Гуляй/муниципальный канал — выборочно с проверкой языка, возраста, формата и даты.

**Резерв:** остальные TG без свежего evidence, LiveTickets под защитой,
Eventworld, общеновостные каналы и неподтверждённые API. Платные API не нужны,
чтобы начать полезный локальный мониторинг. Этот документ не включает источники
автоматически и не запускает расписание; миграция города создаёт только scope.
