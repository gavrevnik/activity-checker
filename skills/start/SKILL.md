# Первый запуск

Короткий диалог: один этап, небольшой отчёт и один выбор за раз. Не выдавать все
инструкции сразу. Прочитать AGENTS.md. Область — рекомендации и их поддержка,
без возвращения скрытых вкладок. Нужны два соседних клона, Node 24+, интернет для
установки и текущий агент. Life Hub, облачный Site, глобальные MCP и ключ OpenAI не нужны.

## 1. Первичная проверка

Сначала `node --version`, затем при Node 24+ — `node scripts/start-check.mjs`. Если Node отсутствует/старый, помочь
установить Node 24+ для фактической ОС и повторить. Диагностика до npm install
читает SQLite read-only и показывает наличие ключей/сессии, локальный health и prerequisites.

Краткий пример: «Готово: Node и два репозитория. Не подключён Telegram.
Apify/Ticketmaster необязательны. Нужна инструкция для всех, только Telegram или
пока продолжим без ключей?» Основание — реальный отчёт, а не пример. Файл ключа
или сессии не подтверждает доступ. Пока человек выбирает, готовить независимые
локальные зависимости; не запускать provider-сбор.

## 2. Установка и личная база

- Проверить соседний `personal-radar/connectors/bootstrap-ts.mjs`, прочитать его README.
  При отсутствии клона помочь получить выданный репозиторий рядом, не угадывая URL.
  GitHub credentials вводятся вне чата. Не настраивать весь Personal Radar.
- `npm ci`, затем `npm run start:setup -- --init`. Helper создаёт личную SQLite без
  demo-карточек с профилем-образцом. Существующую базу не меняет. Pending migrations —
  `npm run db:migrate`, без reset. Не копировать чужие базу, реакции, credentials или session.
- `npm run browser:setup` устанавливает отдельный Chromium из зависимости проекта.
  При ошибке назвать ограничение JS-источников, оставить static/web-путь и не
  объявлять renderer готовым.
- Запустить `npm run dev`, проверить `/api/health` и открыть `http://127.0.0.1:<PORT>/`.
  Занятый порт не разрешает остановку чужого процесса. На macOS после setup можно
  двойным кликом открыть `Activity Checker.app`; Caddy необязателен. Setup запоминает
  текущий Node для nvm/fnm в ignored runtime. Нестандартный PORT/Linux/Windows — терминал.
- Читать [локальный маршрут](references/local-tools.md): schemas доступны через
  CLI без глобальных MCP и облачных подключений.

## 3. Личный профиль и условия образца — до первой подборки

Уточнить город, **языки программы** и основные интересы. Готовые scope — Белград и
Кишинёв, другой город требует подключения. Не выводить языки из страны или имени.
Если человек говорит на молдавском/румынском, не навязывать русский; уточнить,
подходят ли дополнительно русский, английский или другие языки.

Прочитать `/api/profile` целиком: основные интересы, музыка, `additionalPreferences`,
четыре `recommendationPrompts`, `automaticFilters` и `excludedTelegramChannels`.
Внизу «Мой профиль» есть «Дополнительно»: действующие фильтры описаны словами,
их можно отключить. Это единый источник персональных условий, не вкусы в скилле.

**Обязательно** кратко назвать условия образца: языковые/тематические предпочтения,
исключения площадок, названий, тегов и нескольких Telegram-каналов. Отдельно упомянуть
приоритет русского языка и широкое включение русскоязычных выступлений. Спросить:
«Оставить эти условия, отключить условия образца или разобрать выборочно?» До ответа
не объявлять настройку завершённой и не выполнять зависимый сбор.

По ответам сохранить `PUT /api/profile` (убрать служебный `updatedAt` из GET): языки/интересы — в основных полях; исключения и
широкое включение — в additionalPreferences; критерии групп — в recommendationPrompts.
При отключении убрать условия из текста **и** выключить соответствующие
персональные automaticFilters; `excludedTelegramChannels=[]` снимает исключения.
Не оставлять противоречащих языковых условий в скопированных промптах. Если человек
не подтвердил музыку/артистов образца, не принимать их за его вкусы.
В открытом вебе выбрать ту же географию в селекторе; проверить, что календарь
и запрос для модели относятся к выбранному scope, а не к начальному Белграду.
Обязательная защита private network, CAPTCHA, Stars, рекламы/replies и честность
дат/источников — не личные предпочтения и не отключаются.

Проверить GET. Совместимые `/recommendations/settings`, `/filter-rules` и Telegram
monitoring отражают те же реальные настройки. Текст не компилируется в фильтры:
нужные переключатели менять явно по выбору человека и проверять результат.

## 4. Выбранные подключения и готовность

Инструкции только по выбранным сервисам: [connections.md](references/connections.md).
Telegram требует личные api_id/api_hash, uv, Python 3.12 и пользовательскую сессию.
При отсутствии uv помочь установить по официальной инструкции для ОС;
`npm run telegram:setup` сам выбирает bin/python либо Scripts/python.exe.
Номер/код/2FA человек вводит только в своём терминале `npm run telegram:auth`.
Bot token не подходит.

Создать ignored `.runtime/setup/keys.env` (0600) с пустыми полями выбранного сервиса.
Попросить заполнить в редакторе и написать «готово», затем
`npm run start:setup -- --import-keys .runtime/setup/keys.env`. После успешного
переноса в `.env.local` временный файл можно удалить. Не использовать cat/source/eval,
вывод env или токены в argv. Проверять overrides без вывода секретов.

После подтверждения профиля выполнить `npm run start:setup -- --prepare-sources --scope <id>`.
Это только local mapping включённых Knowledge-каналов для записи TG-событий, без
RPC/подписки/auto-join и без Knowledge write. Проверить scoped источники, затем
`npm run start:verify`: доступность реальных local tools, запуск Chromium и статус
Telegram, если настроен. Не печатать raw account/phone. Без Telegram можно продолжить
веб-часть с явным ограничением покрытия.

Apify/Ticketmaster опциональны. Перед реальным quota-limited запуском соблюдать
проектные бюджеты и проверку возможных общих лимитов. Setup не запускает paid Actors.
Cloud Personal Radar MCP по умолчанию не настраивать. Напомнить о личном backup новой
базы; в Life Stack проверить путь в backup config без автоматической загрузки.

## 5. Завершение

Кратко объяснить календарь двух недель, концерты/фестивали, избранное, скрытие и
отказы с оценками. Подборку обновляет внешняя модель по запросу; кнопка копирует
запрос, расписания нет. Предложить: «Обновить рекомендации на текущую неделю?»
После согласия — [activity-recommendations](../activity-recommendations/SKILL.md)
через local tools, сохранить items/rejectedItems и проверить GET/UI. Назвать фактически
проверенные источники и пробелы, не выдавать частичное покрытие за полное.
